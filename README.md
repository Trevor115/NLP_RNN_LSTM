The LSTM model gave better predictions overall because it was able to remember more information from earlier words in the sequence. It also handled longer sequences better than the SimpleRNN. The RNN sometimes failed by forgetting important information from earlier in the input, which led to less accurate predictions. The LSTM performs better because its memory cells and gates allow it to store and use relevant information over longer periods, making it more effective for sequence prediction tasks.
